# FullCarMultimarcaUAI
Trabajo Final UAI - Analista Programador

Proyecto Trabajo Final para la carrera de Analísta Programador a Distancia de la Universidad Abierta Interamericana (UAI).

Trata de un sistema desktop en .net framework 4.8 para la gestión de los clientes, ventas, y liquidación de comisiones a vendedores de una Concesionaria de Autos.
Sistema con esquema de permisos complejo, validación completa de contaseña en loguin e integración con reportes para impresión.
